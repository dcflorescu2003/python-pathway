# Baseline Profile for PyRo (Android)
#
# Human-readable ART profile rules. AGP compiles this into
# `assets/dexopt/baseline.prof` inside the AAB/APK, so ART can
# AOT-compile these startup code paths instead of interpreting them.
#
# Rules that do not match any class/method are silently ignored,
# so this file cannot break the build or the app at runtime.
#
# Syntax:
#   HSPLclass;->method()V   H = hot, S = startup, P = post-startup
#   Lclass;                 include the whole class
